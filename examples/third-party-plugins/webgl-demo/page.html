立方体转起来就说明 WebGL 在插件页里可用——这一项不需要任何 CSP 放开， 是最低门槛。真正的引擎（Unity WebGL / Godot Web / three.js loader）还要靠下面的能力。

页面能力自检

    plugin.json 里 声明了的项应显示「通过」，未声明的应显示「被阻止」。 未声明的能力一律保持禁止（默认最严 CSP），每个能力对应一条明确指令。

    注：isolate（跨源隔离 → SharedArrayBuffer → 多线程 WASM）只在 独立窗口里可能生效；在面板内的沙箱 iframe 里必然为「被阻止」， 因为跨源隔离要求整条文档链都带 COOP/COEP，而宿主主页面并不是隔离的。
